# Artifact-edit skill

Artifacts are versioned source files (DOMAIN.md §10.1), not chat attachments.

1. Choose a kind: `document`, `spreadsheet`, `presentation`, `code`, or media.
2. Write a canonical source file (fixtures in this pack).
3. Propose `artifact.create` (seq 1) or `artifact.update` (seq n+1, parent set).
4. Capture preview evidence (digest + excerpt). Never execute HTML/JS/SVG.
5. Complete only after format validation and quality checks pass.
