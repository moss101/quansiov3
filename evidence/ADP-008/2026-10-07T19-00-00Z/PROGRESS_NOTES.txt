Tool declarations carry model_visible (default true) and host_callable (default false); every call carries its caller (tool_calls.caller). A host-only tool is absent from every model-facing view (the registry's exposed_* and model_visible_names, judged on the newest version; the gateway's schema source; a recording compile's tool summaries) and a model that names one is refused with TOOL_NOT_MODEL_VISIBLE before its arguments are read, recorded as a rejected call and event with no effect; the host path (dispatch_as_host) takes the same capability, policy and Effect Ledger route. The shipped registry has one host-only tool (webdev.preview_scopes); the other 44 are model tools. Packs install by content-hash revision through one path (InstallPack: fetch, verify, compile via the plane's CompilePack, activate in one transaction) with bounded retention of the previous revision, RollbackPack and expiring, redacted, bounded install reports under RLS, readable through GET /v1/packs and the desktop Knowledge surface. A failed install at any phase leaves the previous revision active (outcome retained_previous).
